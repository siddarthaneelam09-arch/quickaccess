QUICKACCESS — INFINITYFREE READY

UPLOAD LOCATION
1. Open your InfinityFree File Manager.
2. Open the existing htdocs folder.
3. Upload/extract the CONTENTS of this ZIP directly into htdocs.
4. Do not create another QuickAccess folder inside htdocs.

IMPORTANT FILES
- index.php   = main website
- api.php     = PHP API/backend
- css/        = stylesheet
- js/         = JavaScript
- favicon.svg = favicon
- data/       = runtime room data
- uploads/    = uploaded files

NOTES
- Keep the folder structure unchanged.
- Do NOT rename CSS/JS files to PHP.
- The app uses normal HTTP requests/polling for shared-hosting compatibility.
- PHP 7.4+ is recommended; PHP 8.x is preferred.
- HTTPS should be enabled on the live site.
- Upload/file size limits are controlled by InfinityFree's PHP configuration.

After uploading, open your domain:
https://YOUR-DOMAIN/
